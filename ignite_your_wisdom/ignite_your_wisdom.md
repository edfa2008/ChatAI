# 点亮智慧

《国产凌凌漆》里面有么一段：达文西发明了一种太阳能手电筒，这种手电筒有光照的时候会亮，没光的时候就需要拿另一个手电筒一照它就亮了。

![img](./image/dawenxi_007.png) 

个人的认知就是另一个手电筒。AI agent是智能的放大器，带来的知识生产能力x100倍放大。AI agent 类似人在驾驭知识挖掘机，关键在于利用AI agent 的长处。
使用Claude code 给我带来的深刻感受是冰火两重天，一方面，感觉AI 能够使我能够10分钟前之前10天的活，另一方面，AI agent 将会让我失业。
AI agent 带来的生产能力的变化，使得能够驾驭AI agent 的话，薪资1000W，否则，只能失业，3000块都赚不到。
在这个AI 时代，带来智能巨变的时候，我们是否能够点亮自己智慧，适应这个时代的变化？
